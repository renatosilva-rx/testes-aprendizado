## 🎮 Como Jogar

1. Escolha um dos **6 níveis** disponíveis
2. **Arraste** os cartões de eventos para os slots numerados
3. Organize na **ordem cronológica** correta
4. Clique em **Verificar** para checar sua resposta
5. Quanto mais rápido e sem dicas, **maior a pontuação!**
